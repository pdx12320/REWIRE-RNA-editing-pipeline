# Authors and contributors

The project team must confirm the citable author list, author order,
affiliations, ORCIDs and corresponding-author details before a release or
publication. No legal names or identifiers are inferred from GitHub usernames.

## Confirmation required

| Field | Status |
|---|---|
| Author names and order | **Required from project team** |
| Affiliations | **Required from project team** |
| ORCIDs | **Required from each author** |
| Corresponding author | **Required from project team** |
| Exact CU5.17 PUF target sequence | **Required from wet-lab/model team; not author metadata and not present in the repository** |

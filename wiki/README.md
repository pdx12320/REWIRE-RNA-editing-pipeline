# iGEM wiki text

This folder contains English copy that can be adapted directly to an iGEM Dry Lab, Software, or Results page.

- `Dry_Lab.md` explains the biological question, experimental design, computational workflow, filtering logic, and interpretation.
- `Results.md` is a structured placeholder for numerical results and figures after the six-sample analysis is complete.

The text deliberately separates completed methods from pending results. Provisional site counts should not be inserted until all samples pass the same pipeline and quality checks.
